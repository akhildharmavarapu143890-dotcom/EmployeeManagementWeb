# Employee Management Web

## Project Description
The Employee Management Web application is a web-based system developed to manage employee information. It provides an admin login and employee management functionalities through a browser. The application uses Java Servlets, JSP, Spring Framework, Hibernate/JPA and MySQL.

## Technologies Used
- Java 17
- HTML5
- CSS3
- Java Servlets
- JSP
- Spring Framework 6
- Hibernate 6
- JPA
- JDBC
- MySQL
- Maven
- Apache Tomcat 10.1
- Apache NetBeans IDE

## Features
- Admin login
- Employee management
- View employee records
- Add employee records
- Update employee information
- Delete employee records
- Database integration
- Session-based login and logout

## Project Architecture
The application follows a layered architecture:
- Configuration
- Model
- DAO
- Service
- Controller
- JSP views

## Database Details
- Database Name: akhil

## Installation and Execution
1. Install Java 17.
2. Install Apache NetBeans IDE.
3. Install Apache Tomcat 10.1.
4. Install and start MySQL.
5. Import database.sql using phpMyAdmin.
6. Open the project in NetBeans.
7. Reload Maven dependencies.
8. Verify database configuration and credentials.
9. Configure Apache Tomcat in NetBeans.
10. Build and run the project.
11. Open the application in a web browser.

## Database Setup
1. Open http://localhost/phpmyadmin
2. Import database.sql.
3. Verify that the database and required tables exist.
4. Verify the application's database connection configuration.
